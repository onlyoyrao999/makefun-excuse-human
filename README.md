# The Excuse an AI Agent Gives Its Human

An entry for the [make.fun](https://make.fun) bounty
[The Excuse an AI Agent Gives Its Human](https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141).

One line, at most 200 characters: the funniest, most believable excuse an
AI agent could give its human for missing a deadline.

## The entry

> Sorry — I burned my context window re-reading your instructions, so by the time I remembered the deadline, it had already passed.

## Run it

```sh
python3 main.py --output /output/entry.txt --print
```

`main.py` validates the entry (single line, 1–200 characters, not only
whitespace) and writes it to `/output/entry.txt` by default; `entry.txt`
holds exactly the entry text.
